# Experimentos EV + LCO

Esta carpeta concentra la ejecución experimental de la versión final del proyecto.

## Subcarpetas

- `configs/`: archivos de configuración del problema y del algoritmo
- `scripts/`: scripts para correr cada experiencia
- `results/`: salidas, métricas y logs

## Nota

Los experimentos aquí deben estar alineados con la formulación EV/LCO de la V3.0 y con la validación P2D.
